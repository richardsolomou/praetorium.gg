All of this works without an account. Ask in plain language and the assistant works out what to look up.

## Look things up

Ask about missions, rules, detachments and datasheets by name, rule number, keyword, weapon or ability. The assistant finds the best match and reads the full record. If a name is ambiguous, it can narrow the search to one faction, mission pack or rules document.

- "Using Praetorium, what's the Toughness and Save of a Space Marines Intercessor squad?"
- "Which detachments do Aeldari have, and what does each enhancement cost?"
- "What's the deployment and terrain layout for this mission in the current mission pack?"

Some assistants also offer two ready-made prompts from Praetorium: **Answer a game-rules question**, and **Explain a mission matchup**, which takes a mission pack and both players' force dispositions.

## Plan an army

> Using Praetorium, plan a 2,000-point Necrons list around two units of Immortals, and tell me which detachments suit it.

The assistant can see each unit's costs, composition, attachments, limits, roles and keywords. Give it a battle size and it uses the limits for that size. Give it a detachment and it also gets that detachment's rules, enhancements, upgrades and stratagems by name, cost and timing. Legends and Crucible datasheets are left out unless you ask for them.

The assistant's arithmetic isn't Praetorium's legality check. To check a list, build or paste it into [Rosters](/rosters), which checks points and the construction restrictions it supports. See [Start a list](/docs/start-a-list) and [Import a list](/docs/import-a-list).

## Simulate combat

> Using Praetorium, how many Intercessors do ten Necron Warriors kill in shooting, and what if the Intercessors are in cover?

The assistant can run Praetorium's combat simulator for one attacking unit, with up to two attached leaders or support units, against one defending unit at full strength. It reports shooting, melee, and shooting followed by melee, with expected models destroyed, wounds lost and the chance to wipe the unit. Every result links to the same matchup on the [simulator](/simulator) page.

You can ask for the modifiers the simulator page offers, such as cover or having charged, and ask it to switch a rule or weapon profile on or off and run it again. Datasheet rules that always apply are on by default. Stratagems and conditional rules stay off until you ask for them.

It uses each unit's default loadout. Name a detachment for either side and it also applies that detachment's rules and offers its stratagems. Otherwise it uses none. To compare specific wargear, use the simulator page. See [Set up a matchup](/docs/set-up-a-matchup).
