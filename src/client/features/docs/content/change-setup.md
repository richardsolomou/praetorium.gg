## Change setup later

**Edit roster setup** in the roster menu reopens setup. Once the list has units, **Review changes** shows what happens to each one before anything is saved: **Unchanged**, **Changed**, **Needs review**, **Illegal** or **Removed**. Illegal units stay in the list for you to fix. **Confirm changes** saves; **Cancel** saves nothing.

![The roster menu open beside the roster header, listing Edit roster setup, Convert rules version, Create variant, Export text and more.](screenshot:build-an-army-roster-menu 'Edit roster setup in the roster menu')

## Rules versions

A saved list keeps its rules version when a balance update or codex arrives, so its points never change under you. A list on an older version says which version is current. **Changed since this list was saved** names the updates that touched units you hold, linking to [Data updates](/data-updates).

**Convert rules version** (in the roster menu or beside that notice) reviews the result like a setup change. Your units and choices are kept and checked against the new rules; anything no longer allowed stays until you replace it. Turn on **Keep the original** to leave this list as it is and save the converted one as a variant.
