## Change setup later

1. Choose **Edit roster setup** in the roster menu and make your changes.
2. If the list has units, **Review changes** shows what happens to each one: **Unchanged**, **Changed**, **Needs review**, **Illegal** or **Removed**. Illegal units stay in the list for you to fix.
3. Choose **Confirm changes** to save, or **Cancel** to save nothing.

![The roster menu open beside the roster header, listing Edit roster setup, Create variant, Export text and more.](screenshot:build-an-army-roster-menu 'Edit roster setup in the roster menu')

## Rules versions

A saved list keeps its rules version when a balance update or codex arrives, so its points never change under you. A list on an older version says which version is current, and **Changed since this list was saved** names the updates that touched your units, with a link to [Data updates](/data-updates).

To move a list to another version, change **Rules version** in **Edit roster setup**, or use **Convert rules version** beside that notice. You get the same review. Your units and choices are kept, and anything no longer allowed stays until you replace it. Turn on **Keep the original** to leave this list alone and save the converted one as a variant.
