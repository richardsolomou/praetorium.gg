Check here if an imported squad size, attached character or translated name doesn't look right.

## Model counts

If the text states a unit's models, those are used. Otherwise the count comes from the model lines it names, then the largest wargear count it states (for example `10x Tesla carbine`), and failing that the unit's minimum size. If the result isn't a size the datasheet allows, the review says what sizes it fields.

## Characters and attachments

Leaders come across attached when the text says which unit they join. Praetorium's own text uses a **Leading:** line, and the official app and New Recruit group them under attached units. WarOrgan doesn't say which unit is the bodyguard, so its characters join the one unit of the group they can lead.

If an attachment can't be made, the unit still imports and the review says why: "this list has no …" or "every … in this list is already led". Attach it yourself in the builder.

## Space Marine chapters

A list that names only Space Marines but fields a chapter's own units, such as Marneus Calgar, imports as that chapter, as long as its units belong to just one.

## Official-app exports in other languages

Names are matched through the translations printed on datasheet and detachment cards and [New Recruit's community translations](https://nrdata.org), which cover French, German, Spanish, Italian, Portuguese, Russian, Chinese, Korean and Japanese to varying degrees. A name neither translates, such as some enhancements, is reported and never guessed.

If a faction's name isn't translated yet, Praetorium takes the faction whose datasheets hold most of the list's units. If every unit is shared by several factions, the review says no faction matched.

A detachment or force disposition with no translation appears in the review. If the matched detachments disagree on a disposition, the review asks you to choose one in setup.
