The **Rosters** tab runs every unit in one list against every unit in another. Choose **Attackers** and **Targets**, then **Run all matchups**. Pairings start at full health (or current health in a battle) with default conditions: supported always-on rules apply; cover, range bonuses and conditional buffs stay off.

- **Show** switches between wounds lost, models lost, uncapped kills and destruction chance.
- **Highlight** marks the best target for each attacker, or the best attacker for each target. Each one is judged on its own, not as a plan for the whole turn.
- Click any cell to open that matchup in full.

Opened from a tournament or club game, the table starts on **Shooting + melee** with the best attacker for each target highlighted.

**Test targets** in the roster menu (**Roster actions**) opens the same table for the list you're editing.

## Benchmarks

Pick **Benchmark targets** as either side to test against a standard set: Cadian Shock Troops, Necron Warriors, Intercessors, Heavy Intercessors, Terminator Assault Squad, Rhino, Ballistus Dreadnought, Leman Russ Battle Tank and Land Raider. Add up to 50 units from any faction, change model counts, or **Reset benchmarks**. Your set is saved in this browser only.
