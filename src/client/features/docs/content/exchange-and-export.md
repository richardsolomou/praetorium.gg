## Exchange codes and QR links

Use an exchange code to pass a list between Praetorium players without losing anything the text format can't hold.

To make one, open a roster's menu (in the builder or on its row in [Rosters](/rosters)) and choose **Exchange code**. The dialog shows the code, **Copy code**, and a QR code unless the list is too long for one to scan reliably. A scanned QR code opens Praetorium's rosters page straight into the import review. Pasting either the code or the whole link into **Import roster** works too.

![The Exchange code dialog with its QR code and the code text.](screenshot:import-a-roster-exchange-code 'Copy code')

An exchange code carries units, custom names, model counts, equipment, attachments, the Warlord, enhancements, setup (including any custom points budget and rule waivers) and the rules version. It never carries unit notes, preparation, reminders, visibility or the sender's account. Importing makes your own copy; the sender's roster is unchanged.

Text and codes keep the rules version they were made with. Praetorium's own text export also names its rules version, so it imports back onto the same one. Text from other apps imports onto the current rules.

## Exporting a list

Open a roster's menu and choose **Export text**. The dialog has **Copy text** and, in the browser, **Download text**. The text includes custom unit names, model counts, equipment, enhancements, the Warlord, attachments, setup and rules version, in a layout other builders can read and Praetorium can import back.

![The Export roster dialog showing the roster as text, with Download text and Copy text.](screenshot:import-a-roster-export-text 'Copy text')

Unit notes, preparation, rule waivers and optional rules are left out. If the roster has entries the builder can't resolve, the dialog warns that they're omitted; fix them before submitting the list anywhere. **Export text** and **Exchange code** are greyed out on an empty roster.

## Visitors and accounts

Without an account, an import becomes the one draft this browser keeps. If you already have a draft, **Import roster** asks you to create an account instead of replacing it ("Keep more than one roster"), and so does accepting a list from someone's QR link. Your existing draft is never overwritten. Signing up moves the draft into your account.

Signed in, an import is saved straight to your rosters and opens in the builder. If the text didn't state a battle size, your default is used, and the roster takes your default visibility.
