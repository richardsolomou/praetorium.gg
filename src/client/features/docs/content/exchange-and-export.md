Use an exchange code to pass a list to another Praetorium player. It holds things the text format can't. Use **Export text** for other apps.

## Exchange codes and QR links

Open a roster's menu, in the builder or on its row in [Rosters](/rosters), and choose **Exchange code**. Send the other player the code with **Copy code**, or let them scan the QR code, which opens the import review. The QR code isn't shown if the list is too long to scan reliably. Pasting the code or the whole link into **Import roster** works too.

![The Exchange code dialog with its QR code and the code text.](screenshot:import-a-roster-exchange-code 'Copy code')

A code carries units, custom names, model counts, equipment, attachments, units that start embarked, the Warlord, enhancements, setup (including any custom points budget and rule waivers) and the rules version. It never carries unit notes, preparation, reminders, visibility or the sender's account. Importing makes your own copy and leaves the sender's roster unchanged.

## Exporting a list

Open a roster's menu and choose **Export text**, then **Copy text** or, in the browser, **Download text**. Other builders can read it and Praetorium can import it back.

![The Export roster dialog showing the roster as text, with Download text and Copy text.](screenshot:import-a-roster-export-text 'Copy text')

The text includes custom unit names, model counts, equipment, enhancements, the Warlord, attachments, setup and rules version. Unit notes, preparation, rule waivers and optional rules are left out.

If the roster has entries the builder can't resolve, the dialog warns that they're omitted. Fix them before you submit the list anywhere. **Export text** and **Exchange code** are greyed out on an empty roster.

## Rules versions

Exchange codes and Praetorium's own text export keep the rules version they were made with. Text from other apps imports onto the current rules.

## Visitors and accounts

Without an account, an import becomes the one draft this browser keeps. If you already have a draft, **Import roster** asks you to create an account ("Keep more than one roster"), and so does accepting a list from someone's QR link. Your draft is never overwritten, and signing up moves it into your account.

Signed in, an import is saved straight to your rosters and opens in the builder. If the text didn't state a battle size, your default is used. The roster takes your default visibility.
