# Local corrections

Place Git patch files under the directory for their source, such as `catalogue/patches/definitions/001-fix-unit-cost.patch`. Patch paths start at the materialized root (`definitions/`, `points/`, `datacards/`, or `battlemaster/`).

`pnpm catalogue:materialize` checks and applies patches in filename order after fetching the pinned source. If an upstream revision changes a patched area, the patch fails rather than silently dropping the correction. Keep each patch focused so its reason and upstream relationship are clear in review. These authored corrections are the exception to the repository’s exclusion of game data; do not add copied catalogues, rules prose, or generated snapshots.

To check one source, run `pnpm catalogue:materialize --source definitions`. Create a patch against that materialized source with `git diff --no-index -- .output/catalogue-sources/definitions/definitions/<file> <edited-file>` and adjust its paths to start with `definitions/`. Run the materializer again to verify the patch against its committed upstream pin.

`definitions/001-invader-atvs-unit.patch` restores Invader ATVs as a Space Marines datasheet. The pinned BSData codex writes its shared entry as an `upgrade`, so no book offers it, although the previous pin wrote the unit as a model. The [pinned Game Datacards Space Marines file](https://github.com/game-datacards/datasources/blob/9c0762c8311db122c0faa9a3a09ef891c3c2d782/11th/gdc/space_marines.json) prints Invader ATVs as a datasheet of 1–2 Invader ATV models, and the [pinned Munitorum Field Manual](https://github.com/BSData/wh40k-11e-mfm/blob/8e0e635674018969fdcfaa64e83d4153ebefad70/data/space-marines.yaml) prices it as a unit. The patch changes only the entry type.

`definitions/002-hide-placeholder-detachments.patch` hides four detachment options the pinned BSData codex names `New Entry`. They carry no rules, costs, or enhancements, and no Game Datacards or Munitorum Field Manual detachment has that name, so offering them would list four empty detachments in every Space Marines book.

`definitions/003-restrict-ceramite-sentinels.patch` hides Ceramite Sentinels outside Imperial Fists. The pinned BSData codex gives Blade of Ultramar, Shadowmark Talon, Forgefather's Seekers and Spearpoint Task Force a modifier that hides each outside its chapter's catalogue, but leaves Ceramite Sentinels without one, so every Space Marines book offered it. The [pinned Game Datacards Space Marines file](https://github.com/game-datacards/datasources/blob/9c0762c8311db122c0faa9a3a09ef891c3c2d782/11th/gdc/space_marines.json) assigns the detachment to Imperial Fists. The patch copies the sibling modifier with the Imperial Fists catalogue ID.

`battlemaster/terrain-labels.patch` adds six corrected Chapter Approved terrain-area labels. The pinned Battlemaster layouts repeat one letter pair and omit another; the [pinned Game Datacards layout records](https://github.com/game-datacards/datasources/blob/9c0762c8311db122c0faa9a3a09ef891c3c2d782/11th/gdc/layouts/layouts.json) link to diagrams that print the correct labels. Each correction names the Battlemaster layout and key, the corresponding Game Datacards layout, and the area name whose letter pair changes. No diagram or upstream layout is copied into this repository.

`datacards/kotc-2.patch` adds the published King of the Colosseum 2.0 board dimensions, links to Play On Tabletop’s objective and terrain diagrams, and the board traced from those diagrams in inches with north at the top. Only the board size and deployment depth are printed. The arena radius, wall span, objective range and wall positions follow the inch dimensions in [Battlebase’s KOTC diagram](https://www.battlebase.app/king-of-the-colosseum-rules), checked against the publisher’s terrain photograph after correcting for camera height. The split between dense and light walls and the ruin floors come from the publisher’s photograph, which Battlebase does not draw. The publisher colours the lowered centre of the north and south arena walls as dense terrain, so the patch keeps those walls continuous.
