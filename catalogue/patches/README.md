# Local corrections

Place Git patch files under the directory for their source, such as `catalogue/patches/definitions/001-fix-unit-cost.patch`. Patch paths start at the materialized root (`definitions/`, `points/`, `datacards/`, or `battlemaster/`).

`pnpm catalogue:materialize` checks and applies patches in filename order after fetching the pinned source. If an upstream revision changes a patched area, the patch fails rather than silently dropping the correction. Keep each patch focused so its reason and upstream relationship are clear in review. These authored corrections are the exception to the repository’s exclusion of game data; do not add copied catalogues, rules prose, or generated snapshots. A correction that adds rules text beyond a single quoted sentence is a commit on a fork branch of its source, pinned in `composition.json`.

To check one source, run `pnpm catalogue:materialize --source definitions`. Create a patch against that materialized source with `git diff --no-index -- .output/catalogue-sources/definitions/definitions/<file> <edited-file>` and adjust its paths to start with `definitions/`. Run the materializer again to verify the patch against its committed upstream pin.

`datacards/insane-bravery-phase.patch` corrects Insane Bravery's erroneous Charge phase tag in the [pinned Game Datacards card file](https://github.com/game-datacards/datasources/blob/9c0762c8311db122c0faa9a3a09ef891c3c2d782/11th/gdc/core.json). Section 15.04 of the [pinned core rule document](https://github.com/game-datacards/datasources/blob/9c0762c8311db122c0faa9a3a09ef891c3c2d782/11th/gdc/core/core_rules.json) specifies the Battle-shock step of your Command phase. `src/core/stratagemCorrections.ts` applies the same correction when loading older immutable snapshots and folding saved battle preparation. It matches only the source card ID and erroneous phase; cost, turn, usage limits and other cards remain source-backed.

`datacards/new-orders-battle.patch` supplies the missing once-per-battle restriction on the pinned New Orders card. The [Warhammer Event Companion v1.2](https://assets.warhammer-community.com/eng_wh40k_event_companion-pl87i44rzn-a7ieny8i9x.pdf), page 2, limits the Command phase secondary replacement to once per battle. `src/core/stratagemCorrections.ts` corrects only that source card's default phase limit when reading existing snapshots and saved preparation. Cost, timing, turn, other restrictions and the saved log remain unchanged.

`editions/current-rosters/definitions/003-restrict-ceramite-sentinels.patch` hides Ceramite Sentinels outside Imperial Fists. The pinned BSData codex gives Blade of Ultramar, Shadowmark Talon, Forgefather's Seekers and Spearpoint Task Force a modifier that hides each outside its chapter's catalogue, but leaves Ceramite Sentinels without one, so every Space Marines book offered it. The [pinned Game Datacards Space Marines file](https://github.com/game-datacards/datasources/blob/9c0762c8311db122c0faa9a3a09ef891c3c2d782/11th/gdc/space_marines.json) assigns the detachment to Imperial Fists. The patch copies the sibling modifier with the Imperial Fists catalogue ID. Fixed upstream in [BSData/wh40k-11e#2363](https://github.com/BSData/wh40k-11e/issues/2363); retain this correction only for the pinned 3 October codex version. Current main carries the equivalent restriction.

`definitions/crucible-tacticus-leaders-exclude-characters.patch` stops Champion of the Chapter [Crucible] and Librarius Adept [Crucible] leading Character units. Their pinned Leader ability names Tacticus units excluding Character and Fly, but the matching `Leading` association checks only Tacticus and not Fly, so the builder offered every Tacticus character as a bodyguard. The patch adds the missing Character exclusion to that branch only; their other wargear branches print no such exclusion. Reported upstream in [BSData/wh40k-11e#3217](https://github.com/BSData/wh40k-11e/issues/3217); drop this patch once the pinned revision carries the fix.

`definitions/canis-rex-embarked-hekhtur-not-infantry.patch` removes Infantry from the Sir Hekhtur model inside the Canis Rex unit. A unit has every keyword of its models (core rules 02.05.01), and the pinned BSData unit fields Sir Hekhtur from the start, so Canis Rex would read as Infantry. His Using Sir Hekhtur ability keeps him embarked until the Knight is destroyed, and the [pinned Game Datacards Imperial Knights file](https://github.com/game-datacards/datasources/blob/ebcd0cbedb197fd8246b7cff580fde3625c6f3f1/11th/gdc/imperialknights.json) lists one Canis Rex model without Infantry. Praetorium does not track the dismounted state, so he is not Infantry there either.

`editions/current-rosters/datacards/` retains the Insane Bravery and King of the Colosseum corrections from the published 3 October codex snapshot. Its explicitly pinned source is fetched independently of the current root, so it must carry those corrections independently as well. Keep these historical corrections unchanged when advancing current sources.

`editions/marine-2026-10-13/datacards/` holds byte-identical copies of the root `datacards/` corrections for the retired 13 October Space Marines rules version, whose pinned sources are likewise fetched independently of the current root. Keep them unchanged when advancing current sources.

`battlemaster/terrain-labels.patch` adds six corrected Chapter Approved terrain-area labels. The pinned Battlemaster layouts repeat one letter pair and omit another; the [pinned Game Datacards layout records](https://github.com/game-datacards/datasources/blob/9c0762c8311db122c0faa9a3a09ef891c3c2d782/11th/gdc/layouts/layouts.json) link to diagrams that print the correct labels. Each correction names the Battlemaster layout and key, the corresponding Game Datacards layout, and the area name whose letter pair changes. No diagram or upstream layout is copied into this repository.

`battlemaster/terrain-areas.patch` groups the Battlemaster footprints that form one terrain area. Battlemaster places each template as its own footprint, so two pieces that make a single area, such as the two central triangles, look the same as two areas that merely touch. Every group's footprints touch except one 0.19″ Battlemaster gap in `purge-vs-recon-02`, and the groups include every central objective pair that [40kdc's `link_group`](https://github.com/Tabletop-Developer-Consortium/40kdc-data/blob/main/schemas/core/terrain-layout.schema.json) marks. Every pinned layout is listed, including those with no groups, and each member names its footprint id and name so a changed source fails rather than regrouping the wrong pieces.

`datacards/kotc-2.patch` adds the published King of the Colosseum 2.0 board dimensions, links to Play On Tabletop’s objective and terrain diagrams, and the board traced from those diagrams in inches with north at the top. Only the board size and deployment depth are printed. The arena radius, wall span, objective range and wall positions follow the inch dimensions in [Battlebase’s KOTC diagram](https://www.battlebase.app/king-of-the-colosseum-rules), checked against the publisher’s terrain photograph after correcting for camera height. The split between dense and light walls and the ruin floors come from the publisher’s photograph, which Battlebase does not draw. The publisher colours the lowered centre of the north and south arena walls as dense terrain, so the patch keeps those walls continuous.

## Custodes preview

The Custodes preview corrections carry rules wording, so they are commits on the [`feat/custodes-11e-preview` fork branch](https://github.com/richardsolomou/wh40k-11e/commits/feat/custodes-11e-preview) that `composition.json` pins for the `custodes-11e` overlays, not patches here. Each commit message records its evidence:

- [`8c058fc`](https://github.com/richardsolomou/wh40k-11e/commit/8c058fc) adds the six provisional character attachment lists, checked on Warmind’s rendered codex pages and corroborated by GW’s detachment preview and Tabletop Battles’ review.
- [`c56cacc`](https://github.com/richardsolomou/wh40k-11e/commit/c56cacc) links the Anathema Psykana army rule to Knight-Centura, Prosecutors, Vigilators, Witchseekers, and their Rhino.
- [`91eb8ba`](https://github.com/richardsolomou/wh40k-11e/commit/91eb8ba) adds Warmind’s 23 base sizes or model footprints and the Anathema Psykana army rule card.
- [`3c57378`](https://github.com/richardsolomou/wh40k-11e/commit/3c57378) gives five stratagems the turn their transcribed When line states, so battles can offer them. Honoured Interred stays out of battles: one turn value cannot express your Shooting phase plus either player's Fight phase.

These are community preview evidence. Reconcile them with the released codex and its MFM before promoting the preview. [The integration tests](../../scripts/custodesAttachments.integration.test.ts) check every attachment pair, both reference directions, rules-version destinations, invalid attachments, every supplied or missing footprint, and the rule on all five Psykana datasheets.
